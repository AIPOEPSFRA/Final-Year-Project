# Backend

This folder contains all backend API and server code.

## Overview
- REST API endpoints
- Server logic and business logic
- Authentication and authorization
- API documentation

## Getting Started
1. Navigate to this folder: `cd backend`
2. Install dependencies: `npm install` or `pip install -r requirements.txt`
3. Configure environment variables in `.env`
4. Start server: `npm start` or `python app.py`
