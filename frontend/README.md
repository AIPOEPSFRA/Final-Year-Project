# Frontend

This folder contains all frontend application code.

## Overview
- User interface components
- React/Vue/Angular code (depending on your choice)
- Styling and assets
- Client-side logic

## Getting Started
1. Navigate to this folder: `cd frontend`
2. Install dependencies: `npm install`
3. Start development server: `npm start`

## Project Structure
```
frontend/
├── src/
│   ├── components/
│   ├── pages/
│   ├── styles/
│   └── App.js
├── public/
├── package.json
└── README.md
```
